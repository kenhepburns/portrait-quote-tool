# 📸 形象寫真報價系統

針對寫真攝影服務設計的線上報價單工具，支援拍攝服務、產品、加購、優惠折扣、條款管理，並可雲端歸檔到 Google Drive。

## ✨ 功能特色

### 拍攝服務
- 拍攝時間 / 拍攝套數 / 妝髮 / 服裝 / 禮服
- 拍攝地點（棚拍 / 外拍 / 客戶指定）
- 拍攝風格、指定攝影師、平假日加價
- 所有欄位皆可勾選啟用 / 隱藏

### 產品與加購
- 主要產品（基本方案）：精修電子檔等
- 加購快速選單：精修、套數、禮服、妝髮、加長時間、相本、原檔等 12 項預設
- 自由新增自訂加購項

### 智能連動邏輯
- 服裝自備 → 自動隱藏「加購禮服」
- 妝髮內含 → 自動隱藏「加購妝髮」
- 啟用「檔案全贈」→ 自動顯示「全贈後加精修」並提示警語

### 優惠折扣
- 預設族群：老客戶回饋 / 企業專案 / 團購專案 / 銀髮族 / 親子優惠 / 自訂
- 百分比 + 手動金額可併用
- 計算順序：小計 → 百分比折扣 → 金額折扣 → 加稅

### 報價條款（皆可勾選啟用）
- 報價有效期限
- 訂金 / 尾款（按比例或固定金額）
- 取消 / 改期條款（內建嚴格 / 標準 / 寬鬆 3 種範本）
- 照片使用授權（個人 / 商業 / 作品集 / 原檔）
- 稅金與發票（含稅 5% / 二聯式 / 三聯式 / 收據）
- 客戶簽名 + 公司簽章欄位

### 系統功能
- 拍攝方案範本庫（一鍵儲存與套用）
- 客戶歷史紀錄
- 報價單狀態追蹤（草稿 / 已寄出 / 已成交 / 已取消）
- 雲端歸檔（Google Drive + Sheets 總表）
- 雙版本 PDF 輸出（簡潔版 / 詳細版）
- JPG 圖片版輸出（方便 LINE 直傳）
- 手機版 RWD
- 雙存儲（localStorage + Google Drive）

## 🌐 Vercel 部署

1. 推送到 GitHub
2. 至 [vercel.com](https://vercel.com) 連接 repo
3. 自動部署完成

## 🛠 技術棧

- Vue 3 (CDN)
- Tailwind CSS (CDN)
- html2pdf.js（PDF 輸出）
- html2canvas（JPG 輸出）
- Google Apps Script（雲端後端）
- 純靜態單頁應用，無需 build
